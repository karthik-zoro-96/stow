# Hacktoberfest Week 3 — idea brainstorm

The live DEV challenge theme is **Slow and Steady** (Oct 19–25, 2026): build something with open-source AI that rewards laziness by doing a small, recurring task for someone. The challenge expects a new project created within its window, so we should choose before building.

## Idea directions

### 1. Fridge-to-list

Take a fridge photo; a local vision model suggests ingredients and a short grocery list. The user fixes guesses before copying the list.

- **Who it helps:** someone who meal-plans or shops for a household
- **Why open AI:** private kitchen photos stay on-device; model can be swapped
- **Demo:** photo → editable ingredients → grocery list
- **Question:** Is “what's for dinner?” actually a recurring pain for someone you know?

### 2. Voice-note-to-family-recipe

Drop in a relative's voice memo; local speech recognition and an open model turn it into a readable recipe with ingredients and steps, while preserving the original recording.

- **Who it helps:** a family member who cooks from memory or saves voice notes
- **Why open AI:** personal recordings can remain local; output is editable and attributable
- **Demo:** audio → transcript → recipe card
- **Question:** Do you have a real recording or person in mind, and would they want this?

### 3. “I’ll do it later” file tidy

Point a local helper at a folder; an open model proposes filenames and categories, then shows a reviewable plan before any changes happen.

- **Who it helps:** someone with a downloads folder full of clutter
- **Why open AI:** files never leave the computer; model suggestions can be inspected
- **Demo:** messy sample folder → proposed plan → user-approved rename/organize
- **Question:** Is there a folder or document pile that someone you know keeps putting off?

### 4. Morning group-chat catch-up

Import an exported chat file; a local model produces a short “what you missed” digest and highlights unanswered questions, without sending messages or exposing the chat to a hosted service.

- **Who it helps:** someone overwhelmed by busy group chats
- **Why open AI:** private conversations stay local; user controls the export and summary
- **Demo:** sample chat export → concise digest → unanswered items
- **Question:** Would a real friend find this useful, and can we use an anonymized sample?

### 5. Tiny admin autopilot

Give a local model a folder of receipts or PDFs; it extracts dates, totals, and likely categories into a review queue, with no automatic filing or deletion.

- **Who it helps:** someone who delays expense tracking or paperwork
- **Why open AI:** sensitive documents stay on-device; every extraction is reviewable
- **Demo:** sample documents → extracted fields → exported CSV
- **Question:** Is there a specific recurring paperwork chore we could make less annoying?

## How to choose

Pick the idea with a real person, a specific repeated annoyance, and a demo we can complete inside the challenge window. The strongest story is the one where we can test it with that person and honestly report what worked and what the model got wrong.
